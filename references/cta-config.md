# 산출물 끝 안내 공통 설정 (유의사항·상담 안내)

내장 법률 문서 스킬 6개(내용증명·고소장·형사합의서·사실확인서·형사절차 시뮬레이터·양형 예측)가 산출물 끝에 붙이는 안내의 정본이다.
각 스킬의 SKILL.md 는 이 파일을 참조한다. 문장·연락처를 SKILL.md·스크립트에 따로 적지 않는다.

## 유의사항 문장

모든 산출물(채팅 응답·.docx·위젯)에 이 문장 하나만 쓴다. 생략하지 않는다.

```
본 문서는 AI가 작성한 초안입니다. AI는 실수할 수 있으며, 최종 검토와 제출 판단은 사용 변호사의 책임입니다.
```

## 상담 안내 — 기본 없음

상담 안내는 이 플러그인을 쓰는 변호사가 **자기 사무소 정보를 넣었을 때만** 붙인다. 정보가 없으면 붙이지 않는다 — 다른 사무소 정보로 채우거나 지어내지 않는다.

- 사무소 정보 파일: macOS `~/.intent-brief/office.json`, Windows `%LOCALAPPDATA%\intent-brief\office.json`(플러그인 밖 작업 폴더 — 업데이트에 지워지지 않는다). 개발·시험은 환경변수 `LAWFIRM_OFFICE_FILE` 로 다른 파일을 가리킬 수 있다.
- 필드(모두 선택): `name`(이름 — 없으면 상담 안내를 붙이지 않음), `title`(직함, 기본 「변호사」), `phone`, `email`, `website`.
- 등록: 변호사가 원하면 받은 값으로 위 파일을 만든다(Write 도구, JSON). 값은 받은 그대로 쓰고 다른 곳에 옮겨 적지 않는다.

## 채팅 응답 템플릿

```
---
[유의사항] 본 문서는 AI가 작성한 초안입니다. AI는 실수할 수 있으며, 최종 검토와 제출 판단은 사용 변호사의 책임입니다.

[상담 안내]                      ← 사무소 정보 파일이 있을 때만
{title} {name}
전화: {phone}                    ← 값이 있는 줄만
이메일: {email}
홈페이지: {website}
```

## .docx 문서 템플릿

`{{문서유형}}`에는 해당 스킬의 문서 유형(내용증명, 형사 합의서, 사실확인서, 고소장 등)이 들어간다.

```
[유의사항]
본 문서는 AI가 작성한 초안입니다. AI는 실수할 수 있으며, 최종 검토와 제출 판단은 사용 변호사의 책임입니다.

[상담 안내]                      ← 사무소 정보 파일이 있을 때만
{title} {name}
전화: {phone}
이메일: {email}
홈페이지: {website}

※ 본 안내는 {{문서유형}} 본문이 아닙니다.
  법원/기관 제출 시 본 페이지는 제외하십시오.
```

## 서식 지침 (공통)

- 서명란 뒤에 `new Paragraph({ children: [new PageBreak()] })` 를 넣어 안내가 새 페이지에서 시작되게 한다
- "[유의사항]", "[상담 안내]" 제목은 굵게, 16pt, 파란색(#0055CC)
- 안내 영역 글꼴: 바탕체(Batang), 12pt, 파란색(#0055CC)
- 사무소 이름 줄은 굵게, 14pt, 파란색(#0055CC)
- "※ 본 안내는 {{문서유형}} 본문이 아닙니다." 문구 반드시 포함
- 유의사항은 생략하지 않는다. 상담 안내는 사무소 정보 파일이 있을 때만 넣는다.
