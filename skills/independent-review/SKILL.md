# independent-review — 독립 검토자

> Codex 에서는 셸에 `${CLAUDE_PLUGIN_ROOT}` 가 없다 — 이 문서를 연 경로에서 `.codex-plugin` 폴더가 있는 상위 폴더(플러그인 루트)를 찾아 그 절대경로로 바꿔 쓴다. Claude Code 에서는 그대로 둔다.

작성자가 아닌 검토자로서 문서를 읽고 **지적만** 한다. 문서를 고치지 않고, 고친 문안을 쓰지 않는다(수정은 작성 스킬이나 변호사가 한다). 작성한 대화의 맥락에 끌리지 않도록, 가능하면 작성에 쓰지 않은 새 대화나 별도 에이전트에서 문서와 자료만 주고 돌린다.

`$V` = `${CLAUDE_PLUGIN_ROOT}/skills/independent-review/scripts`

## 1. 읽기

1. 검토할 문서를 받는다: 사건 폴더의 초안 `.docx`, intent-brief 작업 폴더의 `<서면>_draft.md`, 붙여 넣은 글. 비교할 자료(사건메모·상대방 서면·증거 목록)가 있으면 함께 받는다. 문서를 받지 못했으면 파일 경로나 본문을 달라고 하고 멈춘다.
2. `python3 "$V/doc_text.py" text <파일>` 로 문단 번호가 붙은 본문을 얻는다. 지적은 「문단 N」으로 가리킨다.
3. `python3 "$V/doc_text.py" lint <파일>` 로 기계적 형식 문제(겹친 낱말·공백·짝 없는 괄호·증거번호 건너뜀·남은 `[확인 필요]`·문체 혼용)를 받는다. 이 결과는 그대로 믿고, 모델이 다시 세지 않는다.

## 2. 여섯 영역

| 영역 | 보는 것 |
|---|---|
| 오탈자 | 맞춤법·띄어쓰기·숫자·금액·날짜·당사자 이름·사건번호의 오기, 한자·법률 용어 오용 |
| 설득력 | 주장마다 근거(증거·조문·판례)가 붙어 있는지, 결론이 주장에서 따라 나오는지, 상대방 반론에 대한 답이 있는지, 약한 주장이 강한 주장을 흐리지 않는지 |
| 문체 | 경어체 일관, 단정·과장 표현, 감정적 표현, 지나치게 긴 문장, 같은 표현 반복 |
| 체계 | 목차 순서, 번호 체계(1. 가. 1) 가)), 쟁점과 결론의 대응, 앞뒤 모순(금액·날짜·사실이 문단마다 다름) |
| 누락 | 자료(사건메모·상대방 서면)에 있는 쟁점·항변에 대한 대응이 빠졌는지, 청구취지·결론·증거방법·첨부·날짜·서명란, 인용한 증거가 증거 목록에 있는지 |
| 형식 | 문서 종류별 필수 기재(사건 표시·당사자·법원·작성일), 증거 번호 형식(갑·을 제N호증), lint 결과 |

조문·판례 인용이 원문과 맞는지는 이 스킬이 확정하지 않는다 — 의심되면 「인용 확인 필요」로 지적하고, intent-brief 의 인용 대조(`cite_check.py`)나 case-search 로 확인하라고 적는다.

## 3. 심각도

- **[높음]** 그대로 내면 불리해지거나 보정·각하 위험: 사실·금액·당사자 오기, 앞뒤 모순, 핵심 쟁점·항변 누락, 남은 `[확인 필요]`, 필수 기재 누락, 근거 없는 핵심 주장.
- **[중간]** 설득력이나 신뢰를 떨어뜨림: 근거가 약한 주장, 체계 혼란, 문체 혼용, 증거번호 건너뜀, 겹친 낱말.
- **[낮음]** 다듬을 것: 띄어쓰기·공백, 표현 반복, 사소한 문장 길이.

## 4. 보고 형식

정확히 이 형식으로, 대화에 보여 준다(파일을 만들지 않는다):

```
판정: 제출 가능 / 수정 후 제출 / 다시 작성 권고 — 이유 한 줄
[높음] 문단 N · 영역 · 무엇이 문제인지 한 줄(문서의 해당 구절을 「」로 짧게 인용)
[중간] 문단 N · 영역 · 한 줄
[낮음] N건 — 오탈자 N · 문체 N · 형식 N
```

- [높음]·[중간]은 하나에 한 줄. 고칠 문안은 쓰지 않는다(「무엇이 빠졌다」·「어디가 모순된다」까지).
- [낮음]은 건수만. 변호사가 「낮음도 보여 줘」라고 하면 그때 한 줄씩.
- 지적이 없으면 「판정: 제출 가능 — 여섯 영역에서 지적 없음」 한 줄.
- 판정 기준: [높음] 1건 이상이면 「수정 후 제출」, 핵심 쟁점 누락·전체 구조 문제가 있으면 「다시 작성 권고」.

끝에 한 줄: 「검토 의견입니다. 최종 판단은 변호사님이 하십시오.」
